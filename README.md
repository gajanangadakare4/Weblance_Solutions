# EQUINOX — Website starter

## Files
- `index.html` — page structure and content
- `style.css` — responsive visual system, layouts and CSS animations
- `script.js` — navigation, scroll reveals, pointer glow and optional Three.js 3D particle field

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.
3. For best results, use VS Code with the Live Server extension.

The Three.js library and Google Fonts are loaded from CDNs, so an internet connection is needed for those enhancements. The CSS 3D hero sculpture and core layout still render if Three.js is unavailable.

## Before publishing
- Replace `hello@equinox.example` with your real business email.
- Confirm that the Equinox name, domain and trademark are available in your target markets. This design does not establish name availability.
- Add your actual company address, social links, legal pages and verified service claims.
- The contact link currently opens the visitor's email app. It does not submit to a backend.
- Connect a form service or your own backend when you are ready to receive enquiries securely.
